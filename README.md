# 🥂 Plataforma de Inventario - Js Glitz

Bienvenido a la plataforma web de gestión de inventario para **Js Glitz** – Licores y Vapes EST. 2024 🇨🇴💎

> 🔐 Sistema diseñado para el control eficiente de productos, con roles personalizados para administrador, almacenista y vendedor.

---

## 🚀 Funcionalidades actuales

- Inicio de sesión con diseño personalizado
- Redirección según autenticación
- Pantalla de menú principal con opciones
- Roles de usuario con permisos diferenciados
- Cierre de sesión seguro
- Estilo visual adaptado a la marca Js Glitz

## 🧰 Requisitos

- Python 3.11+
- Git
- Virtualenv

---

## ⚙️ Instalación (modo desarrollador)

```bash
# 1. Clona el repositorio
git clone https://github.com/JuanSoto46/inventario-jsglitz.git
cd inventario-jsglitz

# 2. Crea y activa el entorno virtual
python -m venv env
env\Scripts\activate

# 3. Instala dependencias
pip install -r requirements.txt

# 4. Lanza el servidor
python manage.py runserver
